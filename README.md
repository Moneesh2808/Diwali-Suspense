# ✨ A Cinematic Diwali Surprise for My Papa ❤️🪔💋

An immersive, romantic, and cinematic Diwali surprise web application created especially for **Papa**. Built with **React 18**, **TypeScript**, **Three.js / React Three Fiber**, **HTML5 Canvas**, **Tailwind CSS**, and **Framer Motion**.

---

## 🌟 Visual Journey & Story Sequence

1. **Scene 1 — Romantic Landing Page:**
   - Deep cinematic midnight sky (`#02030A`, `#071126`, `#180D2C`) with twinkling stars and rising golden embers.
   - Traditional Indian brass **Vilaku Deepams** on the lower left and right with multi-wick animated flickering flames.
   - Personal dedication and the first suspense button: `Open Your Surprise ✨`.
   - Interactive hover/tap effects and golden confetti sparkle burst on click.

3. **Scene 3 — "Happy Diwali, My Love ❤️":**
   - 3-Column desktop layout with side brass vilakus, floating embers, and distant celebratory fireworks.
   - Elegant romantic letter rendered in glassmorphic typography with staggered paragraphs.
   - Suspense teaser leading to the second button: `One Last Surprise 💋`.

4. **Scene 4 — Final Love-Kiss Surprise & Finale:**
   - Midnight rose and violet romantic spotlight.
   - Animated silhouette of two fictional adult lovers leaning in for an affectionate kiss.
   - Heartburst particle radiance and sparkle chimes at the moment of the kiss.
   - Final heartfelt love letter: *"For You, Papa ❤️💋"*.
   - `Experience Our Diwali Again ↻` replay button that resets the experience smoothly.

## 🛠️ Technology Stack

- **Framework**: React 18 with Vite & TypeScript
- **Styling**: Tailwind CSS with custom glow and glassmorphism utilities
- **3D Graphics**: Three.js, `@react-three/fiber`, `@react-three/drei`
- **Atmospheric Canvas**: Procedural Canvas firework engines, twinkling starfields & shooting stars
- **Motion**: Framer Motion for cinematic stage transitions
- **Audio Engine**: Procedural Web Audio API synthesizer (ambient romantic pad melody, firework launches, sub-bass explosions, sparkle chimes, muted by default with an interactive toggle)
- **Icons**: Lucide React

## 🚀 Running Locally

### 1. Prerequisites
Ensure you have **Node.js** (v18 or newer) installed.

### 2. Install Dependencies
```bash
npm install
```

### 3. Start the Development Server
```bash
npm run dev
```
Open `http://localhost:3000` (or the port displayed in your terminal) in your browser.

### 4. Build for Production
```bash
npm run build
```
The optimized production build will be generated in the `dist/` directory.

## ☁️ Deploying to Vercel

### Option 1: Via GitHub (Recommended)
1. Initialize git and commit the code:
   ```bash
   git init
   git add .
   git commit -m "feat: cinematic diwali surprise for Papa"
   ```
2. Push your repository to GitHub.
3. Visit [vercel.com](https://vercel.com) and click **"Add New Project"**.
4. Import your GitHub repository.
5. Vercel will automatically detect **Vite**:
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
6. Click **Deploy**. Your romantic website will be live in seconds!

### Option 2: Via Vercel CLI
```bash
npm install -g vercel
vercel
```
Follow the interactive prompts to deploy directly.
